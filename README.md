# C# WPF Calculator Lab

Модульное приложение на C# и WPF, реализующее базовый калькулятор с историей операций. Архитектура проекта строго разделяет бизнес-логику и пользовательский интерфейс, что обеспечивает удобство параллельной разработки, масштабирования и тестирования.

## Структура проекта

```text
project-structure-lab/
├── README.md
├── .gitignore
├── LICENSE
├── src/                   # Исходный код (бизнес-логика: Calculator, HistoryManager)
├── tests/                 # Автоматизированные юнит-тесты
├── docs/                  # Техническая документация и описание архитектуры
├── assets/                # Статические ресурсы (изображения, иконки, шрифты)
└── .github/
    └── workflows/         # Конфигурация CI/CD процессов
```

## Установка и запуск

1. Клонируйте репозиторий на локальный компьютер:

   ```bash
   git clone https://github.com/Zdeviant00/project-structure-lab.git
   cd project-structure-lab
   ```

2. Откройте файл решения (.sln) в Visual Studio 2022 или новее.

3. Выполните сборку решения: Build → Build Solution (или Ctrl+Shift+B).

4. Запустите приложение в режиме отладки (F5 или Debug → Start Debugging).

## FAQ

**Q:** Какой стек технологий используется?  
**A:** C# и WPF.

**Q:** Как запустить тесты?  
**A:** Откройте Test Explorer в Visual Studio и нажмите Run All, либо выполните команду `dotnet test` в корневой папке репозитория.

**Q:** Можно ли использовать этот код?  
**A:** Да, проект распространяется под лицензией MIT.
